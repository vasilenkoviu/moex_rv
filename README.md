# rv-moex

Прогноз реализованной волатильности акций Московской биржи: ориентиры (наивный прогноз, HAR-RV, GARCH), линейные модели, градиентный бустинг и нейросети с честной walk-forward-валидацией.

## Запуск

    .\dev.ps1 test        # тесты
    .\dev.ps1 lint        # проверка стиля
    .\dev.ps1 notebook    # Jupyter Lab
    .\new_branch.ps1 week1-data
